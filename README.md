# HARK_TF_Parser

A python library for HARK2-format transfer function

## Notebook

[Example](https://drive.google.com/file/d/1JMRQNkEgBlxl_QtrBEO6Q7_jlhAA2ojy/view?usp=sharing)

## Installation

```
pip install git+https://github.com/kojima-r/HARK_TF_Parser.git
```


## Usage:
```
wget https://github.com/kojima-r/HARK_TF_Parser/releases/download/v1/tamago_rectf.zip

hark-tf-param tamago_rectf.zip
hark-tf-mat tamago_rectf.zip
```

The original transfer function file can be accessed here.
https://www.hark.jp/download/
